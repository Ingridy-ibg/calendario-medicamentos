## MODIFIED Requirements

### Requirement: Versão do aplicativo no perfil
A tela de perfil SHALL mostrar no rodapé o nome do aplicativo e a versão, no formato "Tomei · versão X.Y.Z".

#### Scenario: Rodapé do perfil
- **WHEN** o usuário rola até o fim da tela de perfil
- **THEN** vê "Tomei · versão" seguido do número da versão do app
